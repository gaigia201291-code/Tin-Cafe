# Tin Cafe
Website tối giản cho quầy cafe, chạy được trên GitHub Pages và hỗ trợ offline sau lần tải đầu.

Tính năng: Order, in hóa đơn tùy chọn, doanh thu/giá vốn/chi phí/lợi nhuận theo ngày và tháng, chi phí mở quầy riêng, sao lưu tự động trong bộ nhớ thiết bị, tải file sao lưu và khôi phục file sao lưu cũ của Cafe Tin.
